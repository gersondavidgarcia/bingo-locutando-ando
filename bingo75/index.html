📖 Reglas del Bingo 75

  • 🎯 Completa una Línea horizontal, vertical o diagonal.
  • 🏆 Completa todo el Cartón (25 números) para cantar Bingo.
  • 🥇 El premio es único: la primera figura y el primer bingo ganan.
  • 🖐️ Puedes marcar números manualmente desde la tabla inferior.

🎯 ¿Qué se juega?

⚙️ Configuración

Elige qué quieres configurar:

Modo actual: —

Elige cómo quieres aplicar los temas en la partida.

Mezcla varios temas en una misma partida. Cada tema cubre 3 cartones seguidos y la secuencia se repite si hay más cartones.

✏️ Editar secuencia

Marca las figuras que quieres jugar y ordénalas como prefieras. La diagonal siempre está disponible.

✏️ Nueva figura

Elige qué resaltado quieres ajustar:

Más bajo = más rápido. Afecta el tiempo que tarda la bola grande en rodar y mostrar el número.

Canta las bolas con voz: "B7", "I22", "N45", "G60", "O75".

Ajusta el volumen de cada sonido por separado.
